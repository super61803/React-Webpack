# React Webpack

Boilerplate for React apps with TypeScript, Webpack, Sass modules, and React Router.

## Requirements

- Node.js `v20.11.0` (see `.nvmrc`)

## Setup

```bash
npm install
```

## Scripts

| Command | Description |
| --- | --- |
| `npm start` | Dev server at http://localhost:3000 |
| `npm run build` | Production build to `build/` |
| `npm run typecheck` | TypeScript check (`tsc --noEmit`) |
| `npm run clean` | Remove `build/` |

## Stack

React 18 · TypeScript · Webpack 5 · Babel · Sass · React Router
